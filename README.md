# Захисти дисертацій НУБіП України (2026)

Самостійний статичний дашборд для GitHub Pages. Усі файли сайту розміщуються в корені репозиторію. Для роботи потрібен браузер із JavaScript та доступ до публічного джерела даних.

## Публікація

1. Створіть публічний репозиторій boiarchukserhii-svg/nubip-defenses-dashboard.
2. Завантажте всі файли цього пакета в корінь гілки main.
3. У Settings → Pages виберіть Deploy from a branch → main → / (root) → Save.
4. Дочекайтеся завершення Pages build and deployment у вкладці Actions.

Адреса після публікації — https://boiarchukserhii-svg.github.io/nubip-defenses-dashboard/

## Дані

Дашборд читає публічний data.json із репозиторію boiarchukserhii-svg/nubip-defenses.
Резервне джерело — копія цього файлу на GitHub Pages застосунку.
Картки здобувачів у дашборді не відображаються.

Під час відкриття завантажується поточний доступний знімок.
У відкритій вкладці повторна перевірка відбувається через сім днів.
Дата оновлення показує дату знімка реєстру. Сам дашборд не запускає збір даних у реєстрі.

Шрифт Zakon завантажується з локальних файлів цього репозиторію. Джерело шрифту — https://mincult.gov.ua/zakon/.
